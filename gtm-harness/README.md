# Makerchamber GTM Harness

The go-to-market side of Makerchamber: content, brand, community, and partnerships.
A one-person AI-leveraged agency in a folder.

**Open this folder (`gtm-harness/`) as your workspace when doing GTM work** so Claude Code
loads the GTM brain and agents rather than the game-studio ones.

Start with `CLAUDE.md`. The core context lives in `brand/` (fill these first via the
brand-and-voice interview). The week runs out of `content/` and `content/calendar.md`.
