Every attention head and feed-forward layer generates an update — a signal about what it found. But a strong signal can destroy what was already known.

The residual connection is the solution: instead of replacing the token's meaning, each layer adds to it. The original is never erased. Updates accumulate like a thread that keeps its first stitch.

You'll see exactly what happens to bank when updates replace versus add.

What layer norm does
Layer normalization rescales the combined vector so all features sit in the same range. No signal is deleted — the relative pattern is preserved, but the loudest voice no longer drowns the rest.

The residual connection is what lets transformers go deep. Without it, each layer would overwrite the last — the model would forget its first impression of bank the moment attention found water.

Instead, the original meaning threads through every layer. Updates accumulate. Normalization keeps them in balance. The word arrives at the output head carrying all of what the model learned — not just the last thing.
